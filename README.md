# Deep State: Networks, States, AI — companion map
Open `index.html` (needs internet for d3 from cdnjs). Data: `data.js` / `data.json`.
Deploy: create a repository named `deepstate` under github.com/anastasiosfountis, upload these files, enable Settings → Pages → Deploy from branch `main` / root.
Live URL (printed in the book's QR code): https://anastasiosfountis.github.io/deepstate/
Also in `/vos`: VOSviewer map file (`deepstate_map.txt`) and network file (`deepstate_network.txt`), and a JSON version (`deepstate_vosviewer.json`, open at app.vosviewer.com).
